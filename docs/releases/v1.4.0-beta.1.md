# Agentic v1.4.0-beta.1

版本日期：2026-09-13。第八周功能、技术文档及重写后的工程日志已通过用户审核并获发布授权。
稳定版仍为已发布的 v1.3.0。本预发布版本按同一仓库、同一 Tag 提供产品与科研两个源码包。

## 本次解决的问题

科研用户此前无法在界面中完整管理训练数据审核、任务和产物来源。本版本增加“微调实验室”，
可以从智能体进入五步向导，选择已审核的数据版本，提交模拟任务，再查看进度、事件和对应 Adapter。
来源、参数和智能体配置被冻结，后续配置修改不会改写已有任务的历史。

**本版本只有 FakeTrainer。** 成功任务生成 JSON manifest 和确定性 checksum，没有模型权重、
梯度更新、真实模型效果评测或在线部署能力。LoRA/QLoRA 参数用于契约与模拟流程，不能视为实际训练支持。

## 新增能力

- 数据注册表：UTF-8 JSONL/manifest 校验、不可变版本、追加审核、来源许可与 PII 声明、
  train/validation 划分、来源/group 检查、精确及近重复检测、内容与 split 哈希。
- 任务生命周期：冻结智能体 revision/数据/模型/参数/代码身份，幂等提交、进度与增量事件、
  取消、重试及失联恢复；单 worker 持久租约与过期结果保护。
- 模拟 Adapter：每个成功任务唯一登记，manifest 完整性、来源链、兼容性、逻辑归档、历史成功
  补登记与有界目录核对。明确标记 simulated、deployable=false、not_evaluated。
- 科研界面：数据管理、五步向导、任务列表/详情、产物列表/详情；版本变更复核、过期响应隔离和
  提交幂等保护。产品模式隐藏入口，服务端独立执行能力检查。
- 共用增量迁移 20260911_07、08、09；产品发行包排除训练及评测模块，保留共用模型、迁移和取消规则。

## 兼容与升级

当前 head 为 `20260911_09`。从 v1.3.0 升级必须备份 SQLite、uploads、Qdrant、存在的训练目录
及私有配置，先关闭 worker 并停止写入，再执行迁移、核验和显式启用。详情见
[升级与恢复](v1.4.0-beta.1-upgrade.md)。禁止删库升级或在运行中覆盖 Qdrant。

未改动现有生成接口、检索模型、冻结评测 profile 或历史会话绑定。新增训练任务可选字段
expected_agent_revision_id/predecessor_adapter_id 保持旧客户端兼容，模拟前驱不代表续训。
共享配置及新发行包仍默认 worker=false；本机此前获批启用不改变分发默认。

对外版本、前端及 OpenAPI 为 `1.4.0-beta.1`，Python/uv 根包为 PEP 440 `1.4.0b1`。
依赖版本和来源未升级；新增真实训练依赖、模型下载、真实训练不属于本候选。

## 验证与限制

第八周已验收数据、任务、产物、UI 和正式合成闭环。候选验证计数、包哈希和实际执行范围以
[发布审批单](v1.4.0-beta.1-approval.md)及[安全审查](v1.4.0-beta.1-security-review.md)为准，
避免把历史验证计为本轮重复运行。

- 本地单用户系统，没有多租户身份认证、分布式训练调度或 GPU 资源释放保证。
- 源文件和 SQLite 没有跨介质原子事务，可能留下未引用文件；不自动清理或覆盖损坏产物。
- PII/近重复扫描不保证发现全部敏感内容、语义泄漏或不当许可，需人工复核。
- 模拟估算不代表真实训练时间、显存、成本或模型质量。正式冒烟的两条合成样本只验证平台流程。
- 尚未在全新联网机器重新安装依赖；源码包不含运行环境、权重或原始数据。

## 后续范围

第九周同时重视 Reranker 与 Scorer，分别准备微调指导、真实训练、基线对照与晋级评测。
