# Agentic v1.2.2

发布日期：2026-09-08

状态：已通过用户审核并授权发布。

本次补丁将前端改为已选定的“暖白编辑”风格。资料空间、快速对话、智能体对话、设置和上传/创建弹窗沿用既有功能与布局，以暖白纸感面板、陶土橙主色、衬线标题和细边框建立一致的视觉层次。

## 主要变化

- 统一暖白背景、纸感面板、陶土橙按钮、小圆角与轻阴影，移除原有蓝紫渐变和装饰光晕。
- 大标题、内容标题使用本机可用的衬线字体；正文保留原有无衬线字体，无新增字体下载或打包。
- 统一 Element Plus 输入框、下拉框、弹窗、提示、标签与焦点状态的主题。
- 为来源引用保留可区分的暖色/橄榄色，成功、警告和错误状态保持明确的语义色。
- 修复资料表格隐藏辅助标签造成的横向溢出，保留表格内部横向滚动。
- frontend、backend 包版本、锁文件根项目版本及 OpenAPI 应用版本同步为 `1.2.2`。

## 兼容性与范围

- 页面模板、业务逻辑、API 路径与响应字段保持不变。
- 不修改数据库 schema、资料索引流程、模型调用或 RAG 评分算法，不需要数据迁移。
- 不引入或升级依赖，不增加外部字体、图片或其他第三方资源。
- baseline profile registry 保持现状；历史 `v1.2.1` Benchmark 证据不改版本。
- Week 7 AgentProfile 后端配置、ORM/迁移、测试和研发文档不属于本次发布。

## 验证

- 前端生产构建与 Vue/TypeScript 类型检查通过。
- 23 项浏览器页面/响应式检查通过，未出现浏览器脚本错误。
- 验证覆盖资料空间与空状态、资料详情、快速对话、智能体对话、设置、折叠/移动侧栏，以及创建/上传弹窗、下拉选择和引用展开。
- 页面检查覆盖桌面及 1024、768、390 像素宽度；五个主要页面的生产构建主题加载已核对。
- 浏览器检查使用隔离示例接口与内容，不调用真实模型或写入用户资料；不代表重新验证真实后端的上传、索引和模型服务。
- 本次发布准备：前端 Vitest 10 项通过；Oxlint、ESLint、Vue/TypeScript 与生产构建通过；后端锁文件离线检查通过（169 packages）。

## 发布授权

用户于 2026-09-08 明确批准推送，授权创建版本提交及 annotated tag `v1.2.2`，并推送到 `SevChu/RAG-Agent` 的 `main` 与对应标签。Week 7 AgentProfile 的独立本地改动不包含在本次发布中；GitHub Release 的创建不属于本次推送范围。
