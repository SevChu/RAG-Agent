## 二、验证与效果边界

- 版本号统一后：后端 402 passed（35.86 秒），前端 25 passed；Ruff、strict Mypy
  （113 源文件）、前端类型、只读 Oxlint/ESLint、1,756 模块生产构建和离线锁检查通过。
- 最近浏览器证据：产品 22 项、科研 3 项，页面错误 0。此次仅版本/文档/本机配置调整，
  沿用上一轮界面证据，不把它计为新一轮真实供应商测试。
- 产品解压包阻断 app.evaluation / PyArrow 导入后的 80 项回归通过；具体研究引用案例
  在完整仓库测试覆盖。发行包文件清单、SHA-256、敏感模式与链接检查记录在本地 audit.json。
- 模拟测试覆盖四供应商路由，不发真实外部请求。性能测量中千个智能体解析为 1～2 次 SQL，
  没有新增模型调用；该指标仅是本地配置解析，不代表完整 RAG/生成延迟。
- 本周没有证明回答质量提升、跨客户 Benchmark 可迁移、多智能体自主协作、长期记忆、
  训练/微调或多租户鉴权；这些功能和证据不列为本次达标项。
- 尚未在全新联网机器执行依赖安装；评测集和模型不随源码包分发。

## 三、仓库与本地研发环境

采用现有 **SevChu/RAG-Agent 单仓库 + v1.3.0 单一 Tag + 产品/科研两份源码包**。
同一核心、数据库迁移和修复同步维护，不建立两套易分叉的仓库。完整仓库包含科研代码，
产品包仅排除研究文件和默认关闭科研功能，不构成科研源码的访问权限隔离。

本机开发目录继续使用完整源码；未跟踪的 .env 已配置 AGENTIC_EDITION=research。
科研注册表与现有 PyArrow / scikit-learn / 开发依赖已检查可加载，本机模型、数据和备份保留。
产品包与共享 .env.example 仍默认 product；开发者私有配置不进入 Git 或任何发行包。
研究模式保留全部当前已实现功能，仍遵守空间、工具、版本和实验流程约束。
