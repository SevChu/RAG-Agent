# Agentic v1.2.0

发布日期：2026-09-04

Agentic v1.2.0 在 v1.1.1 基础上增加可机器校验的实验治理与一个角色受限的 NLI 幻觉 span
定位 profile。本版本没有把离线评分器接入生产回答链路，也不包含仍待单独审核、计划作为
`v1.2.1` 发布的 Week 6 Extra。

## 主要变化

- 新增 Week 6 Experiment Registry，冻结假设、唯一变量、revision、seed、指标和审批状态；
- 在配置与运行时共同阻止未批准的 test split 进入优化；
- 新增 domain、class、length、evidence count、error type 五维匿名切片契约；
- 完成 Dense Top-100 直接重排、两阶段 Completeness 和句级 NLI Span 三项 validation 对照；
- 只让通过 validation 稳定性门且经用户批准的 NLI 候选执行一次隔离 RAGTruth test；
- baseline profile registry 升到 `1.1.0`，新增 `ragtruth-nli-span-localization`；
- 同步 backend、frontend 与 OpenAPI 版本到 `1.2.0`。

## 决策结果

| 候选 | 决策 | 原因 |
|---|---|---|
| Dense Top-100 → Reranker | `provisional` | nDCG 均值改善很小，paired bootstrap CI 跨 0 |
| Two-stage Completeness | `deferred` | 跨领域 bootstrap CI 跨 0，部分领域明显退化 |
| Sentence NLI Span | `accept_advisory_profile` | 唯一通过 validation 稳定性门，并通过一次 final test 的四项数值门 |

Day 2/3 未访问 official test，也未进入 profile registry。

## 使用限制

- Span recall 从 `0.347892` 降到 `0.302058`；
- source-cluster bootstrap 95% CI `[-0.000657, +0.017168]` 跨过 0；
- candidate response AUPRC 低于历史 lexical coverage profile 的 `0.504173`；
- RAGTruth test 已在 Week 5 用于经典基线，因此这里只能称 candidate-isolated test；
- profile 只允许 offline/advisory/span-focused 分析，不替换 lexical response profile，不得作为
  production blocking 或在线默认配置；
- 公开英文 Benchmark 结果不能外推为中文真实流量质量。

## 兼容性与数据边界

- 不改变生产 RAG、数据库 schema 或现有 API 路径；
- 不需要用户迁移配置或本地资料；
- 原始 Benchmark、test-only JSONL、模型权重、Dense/NLI 缓存和逐样本结果不会进入 GitHub；
- tracked 结果只包含聚合指标、哈希、协议和限制；
- 第三方模型与数据仍遵循 `THIRD_PARTY_NOTICES.md` 中的上游条款。
