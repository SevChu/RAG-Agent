# v1.3.0 数据与安全审查

日期：2026-09-09。状态：当前工作区技术审查完成，联合验收和发布审批待完成。
范围为 Week 7 相对 v1.2.2 基线的新增/修改源码与文档；元数据尚未冻结，发布前需复核最终 diff。

## 数据与凭据边界

- AgentConfiguration 严格字段校验；保存模型供应商/名称，凭据由服务端环境解析，不进入快照。
- 管理选项只返回供应商配置状态和环境变量名称；API/SSE 的新增诊断只包含身份、版本、
  哈希、供应商、请求模型和实际模型，不复制 Settings 或凭据。
- 测试、浏览器脚本和测量使用合成内容；真实 HTTP 客户端在四供应商测试中接入 MockTransport，
  验证对应凭据选择且不在返回事件中泄露测试密钥。没有真实资料外发或模型/数据下载。
- 正式数据库只读核验，备份 manifest、升级明细、截图、测试库和测量临时输出不进入候选。
  公开报告只保留聚合数量、状态与备份标识，不包含资料正文、名称、会话内容或逐行哈希。

## 配置与运行约束

不可变 revision、会话复合外键及 UPDATE/DELETE/REPLACE 保护由迁移与 ORM 测试覆盖。
并发写入使用 row_version，配置追加与身份更新同事务；历史恢复追加新版本。
运行时重查启停、版本哈希、模型唯一归属和允许空间；服务端上限与工具开关仍有效。
空间/工具冲突在检索或生成前拒绝，不能通过切换请求模型或智能体重绑旧会话。

研究引用只能使用冻结注册表明确允许的 offline/advisory 用途。在线解析不打开评测注册表或
运行评测器；没有改变 Week 6 Day 2 reject、Day 3 deferred 或 NLI 的 offline/advisory 边界。

## 使用与发布边界

智能体空间白名单是本地应用内约束，不是多租户鉴权。系统提示保留任务约束，但不能据此
承诺消除所有模型提示注入；资料隔离和工具权限由代码执行。SSE 断开分支验证不保存完整
消息对，但已发出的供应商请求可能仍完成并产生 Token 用量。

没有新增第三方依赖、字体、模型或数据资产；源码许可范围沿用现有 LICENSE 和
THIRD_PARTY_NOTICES。当前不发布 dist 或依赖包；若后续分发制品，按 CONTRIBUTING 对
实际制品补 SBOM 与许可清单。

本轮允许进入用户联合验收；正式发布前须同步版本、确认候选范围并按
[发布清单](v1.3.0-release-checklist.md)完成相应授权。
