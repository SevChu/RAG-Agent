# Agentic v1.3.0

发布日期：2026-09-11。第七周基础任务、周日志与两版 README 已经用户最终审核。
应用元数据为 1.3.0；SevChu/RAG-Agent 同一仓库、Tag v1.3.0，提供产品与科研两个源码包。

本版本引入可独立配置的智能体及不可变配置历史。会话创建时固定版本，之后修改智能体
只影响新会话；现有默认会话继续使用兼容路径。

## 主要变化

- 分离产品与研发/科研模式及源码包：普通智能体全流程不需要 Benchmark，产品包排除
  评测模块；科研包包含研究工具，数据集按实验需要另行准备，不自动下载。

- 新增 AgentProfile、不可变 revision 与可空会话绑定；配置带规范化 SHA-256，变更追加版本。
- 提供创建、复制、编辑、启停、逻辑删除、版本查询和恢复 API；并发编辑明确返回冲突。
- 新增智能体管理页面、分组配置和版本比较，两类对话可选智能体并显示固定版本。
- 统一解析模型、补充提示、允许空间、工具和上下文/检索上限，复用快速对话、问答、总结、
  组卷及计划/修复链路；JSON、SSE 和消息诊断记录绑定版本和实际模型。
- 停用或依赖失效时阻止新生成，历史仍可读；恢复配置创建新 revision，复制产生独立身份。
- 修复组卷联网分支的服务端开关检查，收紧绑定试卷续写的资料/联网范围验证。
- 前端保存冲突保留草稿；会话切换、历史恢复和生成回调忽略过期响应，减少误发送或错误导航。

## 升级与兼容

新增 Alembic 迁移 20260907_05 与 20260910_06；升级前备份 SQLite、上传文件和 Qdrant。
旧会话绑定字段保持 NULL，不回填或重写历史。后端 app.main:app、默认 8000、前端 5173
及原 API 路径不变。详见[升级说明](v1.3.0-upgrade.md)。

锁定依赖版本/来源未升级；显式研究依赖移入可选 research 组。没有新增模型或数据集；冻结评测 registry 不变。
研究配置仍限 offline/advisory，不会自动执行评测或成为生产门禁。

## 已知边界

- 仍是本地单用户应用，智能体允许空间不是多用户账号授权体系。
- 版本固定配置，不冻结资料内容、环境凭据、服务端上限或外部模型输出。
- 补充提示增加输入长度；固定版本与记录实际模型不保证回答逐字复现。
- 快速对话不读取资料，总结保持仅资料；生成仍遵守既有证据和引用约束。
- SSE 使用完整生成后的分段输出；中断不保证已经发往供应商的请求立即停止或免计费。
- 不提供智能体硬删除、自动协作、长期记忆、Adapter、训练或新在线评分算法。
