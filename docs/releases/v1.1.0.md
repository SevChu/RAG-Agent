# Agentic v1.1.0

发布日期：2026-08-30

Agentic v1.1.0 将项目从基础本地 RAG 应用扩展为具备公开 Benchmark、经典评分基线和后续
算法/微调研究入口的通用智能体实验平台。项目仍为公开可见、非开源的个人专有项目；Severus
Chu 的版权主张只覆盖其拥有版权的 Agentic 原创材料，不覆盖第三方依赖、模型、Benchmark
原始资料或其他上游内容。

## 主要新增

- 完成 Agentic、资料空间、空间资料和智能体对话的通用产品语义迁移；
- 建立公开 Benchmark Registry、统一 Adapter、审批状态机、安全下载和 frozen manifest；
- 完成 BEIR FiQA-2018 的 BM25、BGE-M3 Dense、RRF 和 BGE Reranker 检索基线；
- 完成 RAGTruth 的回答级幻觉检测、校准和字符级 span 定位基线；
- 完成 RAGBench 的 adherence、relevance、utilization、completeness 经典评分基线；
- 冻结机器可读 baseline profile 1.0.0，记录数据、模型、参数、指标和用途限制；
- 发布严格白名单导出的聚合 Benchmark JSON/CSV，不发布原始数据或逐条预测；
- 纳入第 6～11 周评分算法、AgentProfile、微调、记忆和自有金标集研发路线。

## 公开数据包与脱敏

| 文件 | SHA-256 |
|---|---|
| `benchmarks/v1.1.0/results.json` | `2615be9ca32717eb28d209f65ec8949a7ba0278f35589274825100d646f71f06` |
| `benchmarks/v1.1.0/metrics.csv` | `4ff8bac3afa782af575c0e69d77cebc407c616b66f8ed7d0a8482e2246566ef0` |

公开包只包含聚合指标、协议、模型/数据 revision、硬件类别和本地未发布产物的 SHA-256。它不含：

- 原始 FiQA、RAGTruth 或 RAGBench 文件；
- query、answer、context、document、prompt、样本 ID 或逐条 prediction；
- 资料空间、对话、数据库、上传资料或本地绝对路径；
- 模型权重、API Key、外部调用正文或私人测试数据。

导出器和回归测试位于 `backend/scripts/export_public_benchmark_results.py` 与
`backend/tests/test_public_benchmark_results.py`。原始数据、run、缓存和 prediction 继续受
`/backend/datasets/` Git 忽略规则保护。

## 已知限制

- 公开 Benchmark 均为英文，不代表中文真实用户流量；
- FiQA 仅代表金融检索域；
- RAGTruth span 边界仍较粗；
- RAGBench adherence 类别不平衡，不能只比较 F1；
- baseline profile 是离线研究参考，不是生产回答拦截器；
- AgentProfile、训练作业、Adapter 管理、长上下文和资料空间记忆仍在后续路线中。
