# Agentic v1.2.1

发布日期：2026-09-07
状态：已完成用户最终审核并发布

Agentic v1.2.1 是 Week 6 Extra 的证据与治理补丁。它没有新增 production profile，而是把
Day 2 检索候选的一次性 FiQA test 失败，以及 Day 3 Completeness 候选的外层确认失败，固化为
可复现、可审计的否决记录。

## 主要变化

- 新增 Day 2/3 validation 稳健性复评；
- 新增 FiQA 未使用 train queries 的确认性运行与机器决策；
- 新增 RAGBench 外层留一领域确认；
- 新增经审批的一次性 FiQA dense-direct rerank final-test runner；
- 新增无样本内容、无本机路径的 `benchmarks/v1.2.1` 公开聚合结果；
- backend、frontend 与 OpenAPI 候选版本同步到 `1.2.1`；
- baseline profile registry 保持 `1.1.0`，profile 数量和内容不变。

## 最终决策

| 候选 | 补充证据 | Final test | 决策 | Profile |
|---|---|---|---|---|
| Dense Top-100 → Reranker | FiQA train 确认四门通过 | FiQA test 主门失败 | `reject` | 不进入 |
| Two-stage Completeness | 外层留一领域四门失败 | 未运行 | `deferred` | 不进入 |

### Day 2 FiQA test

| 指标 | Baseline | Candidate | Delta |
|---|---:|---:|---:|
| nDCG@10 | 0.429862 | 0.429352 | -0.000510 |
| Recall@100 | 0.699345 | 0.718779 | +0.019434 |
| MRR@10 | 0.516222 | 0.513520 | -0.002702 |
| MAP@100 | 0.368163 | 0.368598 | +0.000435 |
| 平均时延 | 698.670 ms/query | 674.726 ms/query | -23.945 ms/query |

paired query nDCG@10 bootstrap 95% CI 为 `[-0.005411, 0.004049]`。候选守住 Recall 和时延，
但均值为正与 CI 下界为正两项主门失败，因此依协议拒绝，不调参、不重跑、不进入 advise profile。

### Day 3 外层确认

12-domain macro Spearman delta 为 `-0.003987`，95% CI
`[-0.030626, 0.021197]`，exact sign-flip `p=0.790527`，macro RMSE delta
`+0.002524`。四项预登记门全部失败，因此保持 `deferred`，不访问 RAGBench test。

## 为什么仍发布负结果

- 固定已经消耗的一次 official test，防止同一假设因结果不佳而重复测试；
- 保留 train/validation 与 test 方向不一致的证据，避免选择性报告；
- 为未来真正改变假设、模型或独立数据来源时提供可比较的基线；
- 明确阻止这两个候选被误接入 AgentProfile 或生产链路。

## 数据与兼容边界

- 不改变生产 RAG、数据库 schema、API 路径或前端业务行为；
- 不需要用户迁移配置或本地资料；
- 不修改 `baseline-profiles.json` 与 `experiment-registry.json`；
- 原始 Benchmark、qrels 内容、TREC run、逐条预测、缓存与模型权重不进入 GitHub；
- final-test 本地 summary 含模型路径，因此不直接发布；公开结果由哈希绑定的导出器重新生成；
- 公开目录只含 aggregate metric、count、CI、gate、decision、哈希和限制；
- FiQA 非商业研究限制及其他上游条款继续适用。
