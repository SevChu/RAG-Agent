## 数据处理设计

### 原始数据与模型不发布

- `/backend/datasets/`、`/datasets/`、`/models/` 和 `*.safetensors` 均由根 `.gitignore` 排除；
- `git ls-files backend/datasets` 与 `git ls-files models` 均返回 0 个文件；
- 候选集合没有 `.jsonl`、`.parquet`、`.npz`、`.safetensors`、`.pt`、`.bin` 或 `.onnx`；
- test-only JSONL、TREC run、Dense/NLI cache、模型权重和完整 summary 不进入 GitHub。

### RAGTruth split 先隔离再解析

train-only 与 test-only 派生器先用受限正则读取每行顶层 `split`。不属于目标 split 的 response
在 `json.loads` 前直接跳过；source 也先按已选 `source_id` 过滤，再解析保留行。派生前重新校验
父文件 SHA-256，派生后校验 split 计数、引用完整性与唯一性，并拒绝覆盖已有目录。

### 受 Git 管理的结果只含聚合

tracked profile、registry、报告和发布说明只保存 aggregate metric、count、CI、p-value、模型/数据
revision、SHA-256 与限制。runner 明确记录：

- `prediction_artifacts_written = 0`；
- `contains_sample_ids = false`；
- `contains_source_or_response_text = false`；
- `contains_gold_spans = false`；
- `contains_per_sample_scores = false`。

模型身份写入 summary 前会移除本地 `path`；受管理文档中不记录 Windows 用户目录或其他本机用户路径。
