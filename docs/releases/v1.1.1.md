# Agentic v1.1.1

发布日期：2026-08-31

Agentic v1.1.1 是不改变运行行为、API 契约或 Benchmark 数值的许可边界补丁。功能和评测基线
继续沿用 v1.1.0；本版本修正专有版权声明的适用范围，并建立第三方材料与未来制品分发门禁。

## 修订内容

- 重写根目录 `LICENSE`，明确专有条款只覆盖 Severus Chu 拥有版权的 Agentic 原创代码、文档
  和设计；
- 将第三方库、传递依赖、模型、权重、数据集、Benchmark、外部内容和商标排除在 Agentic
  专有版权主张之外；
- 新增 `THIRD_PARTY_NOTICES.md`，记录 FiQA、RAGTruth、RAGBench、BGE、PaddleOCR 及当前
  依赖许可边界；
- 标记 `orjson`、`crc32c`、Lightning CSS 等 MPL/LGPL 组件，要求未来 Docker、桌面安装包、
  前端 bundle 和离线依赖包按实际制品生成 SBOM 与完整许可清单；
- 同步 README、Benchmark 说明、技术文档、贡献规范、研发路线与 CHANGELOG。

## Benchmark 边界

- FiQA 聚合指标仅作为本地非商业研究评测的公开参考，不授予商业使用权；
- RAGTruth 发布仓库为 MIT，但其 MS MARCO、Yelp、CNN/DailyMail、新闻等底层内容保留原权利；
- RAGBench 数据卡为 CC BY 4.0，各组成数据集的通知和限制继续适用；
- `benchmarks/` 不属于 Agentic 专有软件许可的授权范围；聚合指标不重新许可底层数据。

本补丁没有增加或重新上传原始数据、问题、上下文、回答、逐样本预测、模型权重或第三方
二进制。v1.1.0 的聚合数值文件保持不变：

## 兼容性

- 后端、前端、数据库 schema 和 API 路径没有行为变更；
- v1.0.0 与 v1.1.0 标签保持不变；
- 使用者只需阅读更新后的 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`，无需迁移数据或配置；
- 未来商业发布、收费服务或包含第三方二进制/模型/数据的制品仍需专项法律复核。
