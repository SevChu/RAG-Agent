# v1.4.0-beta.1 发布安全与分发审查

状态：源码与分发边界已核对，技术文档及日志复审通过，用户已明确授权发布。

## 公开与私有边界

公开范围为原创代码、配置模板、迁移、测试、技术文档和允许的合成截图/聚合证据。真实数据库、上传
资料、向量、训练样本、模型权重、.env、备份、运行日志和逐样本预测不进入源码包或 Git 提交。
既有许可证和第三方声明保持；本版本不新增模型、数据集或第三方训练依赖。

## 两种源码包

产品包排除 app/evaluation、app/training 及科研脚本/文档，保留共用 ORM、迁移和业务接口；科研包
包含训练平台源码，但同样排除所有私有资产。两包都有自己的 README、默认模式、发行能力标记和
逐文件 SHA-256 manifest，均为 source-only，不包含 venv/node_modules/dist。

完整源码中的 product 模式与产品包不同：前者保留训练路由但返回 403，后者不注册这些路由。
共用前端含训练组件不等于运行权限；该分离也不是源码保密或多租户安全边界。

## 训练数据与产物边界

数据许可、PII、split 与去重检查不能替代人工审核；训练 Registry 拒绝 test，但无法判断用户把
真实 test 伪称为 train。冻结数据库可能包含智能体系统提示，必须作为私有资产保护。
API 不返回冻结提示正文、样本、worker token、幂等键或原始异常。模拟产物不可部署。

受控文件入口拒绝路径越界、符号链接/junction 和硬链接；同 OS 账户可直接修改文件的风险仍存在。
文件与数据库不是跨介质原子事务，孤儿文件不自动清理；不把补登记当作修复篡改文件。

## 审计结果

- 核对候选科研白名单 447 个源文件，已知本机凭据精确比对无匹配；不输出密钥值。
- .env、业务库、训练目录、备份、output 和 tmp 均被 Git 忽略；发行目录白名单排除私有路径及载荷。
- 两份锁文件与 v1.3.0 比较，仅项目版本改变，第三方依赖版本/来源不变。
- 初始双包逐文件 SHA-256 全部匹配；实际解压产品/科研包回归通过，具体计数见
  [审批单](v1.4.0-beta.1-approval.md)。最终包逐文件对照、路径、类型和链接检查写入本地 audit.json。
- 七张本周截图来自已验收的合成场景；正式截图只截取模拟产物区域，没有真实会话正文或凭据。
- 变更文档的本地链接已核对；完整清单与 diff 提供给用户审阅，历史日报不重写为当前完成状态。

这些检查验证指定的分发范围和已知凭据排除，不宣称全量 DLP、恶意软件扫描或多租户隔离已经实现。

## 发布门

用户要求本周修改的技术文档经过审阅后方可发布。审批目录必须覆盖相对 v1.3.0 的所有新增/修改
Markdown、配置模板及技术附件；候选哈希在本地保存，批准后核对内容漂移。GitHub 将使用
prerelease 且不覆盖 latest；用户已于 2026-09-13 明确批准 commit、Tag、推送和 Release，按审批范围执行。
