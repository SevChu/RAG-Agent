## 实现结果

### 智能体管理

侧栏新增“智能体管理”，路由 /agents。列表展示名称、描述、模型、当前版本、允许空间数和
启用状态，提供创建、编辑、复制、启停、版本记录及两类对话入口。列表每页 20 项，历史版本
分页加载；会话选择器读取全部分页，避免只显示前 50 个配置。

编辑分组覆盖身份、补充提示、供应商/模型、空间白名单、联网权限、上下文、检索参数和
研究评测引用。供应商未配置、模型歧义、候选数量关系、输入范围及失效评测引用有明确提示。
空空间列表只允许快速对话。研究引用显示“离线评测/辅助分析”，不会自动触发评测。

保存提示说明配置只影响新会话；只改名称和描述时不追加配置版本。复制产生独立身份。
版本记录展示变更说明、时间、与当前版本相比变化的配置分组、所选版本的模型和提示，
可展开完整配置与哈希；恢复通过原 API 追加新版本，保留旧会话和历史版本。

并发冲突保留未保存草稿，显示服务端原因；用户可选择重新载入最新版本后继续编辑。
启停和恢复使用读取时的 expected_row_version，不通过静默重试覆盖其他修改。

### 对话闭环

快速对话和资料对话共用 ConversationAgentControl。新会话可选择智能体或默认兼容路径；
管理页“快速对话/资料对话”带入选择。资料对话仅展示该版本允许的空间，已有会话锁定空间。

已有绑定会话按固定 revision 显示名称、版本、模型和工具权限，不跟随当前最新版本。
固定模型不再发送全局模型选择参数；默认会话继续按全局模型选择运行。
更换智能体必须新建会话，不能原地改变旧绑定。刷新后从会话绑定 ID 恢复。

停用、模型失效/缺凭据、空间删除和配置读取失败时阻止发送，保留历史消息供查看；提供
刷新状态入口，窗口重新获得焦点时也会刷新。服务端继续执行最终权限检查。
联网控件显示有效开关，禁止联网时不显示成“已开启”；资料请求同步收紧来源范围。

历史恢复和生成回调增加过期响应检查。用户快速切换会话时，较早返回的数据不会把页面
切回旧会话；创建请求被中断后不会继续导航或发送。历史加载期间以及无效历史入口禁用发送，
避免误建默认会话。流式失败、中断和旧会话兼容行为保持。

### 界面与可访问性

沿用 v1.2.2 的纸色背景、陶土色操作和现有侧栏。新增表单有明确标签、输入约束与错误区域；
弹窗挂载到页面根部，避免页面动画容器裁切。移动端表单单列，版本列表折行和滚动。
已检查 1440×1050 桌面、折叠侧栏及 390×844 移动端；测试检查无横向溢出，并检查保存、
历史版本、移动端弹窗、抽屉导航和停用历史界面的截图。

## 如何使用

按 README 原命令启动服务，打开侧栏“智能体管理”（/agents）。创建并保存配置后，点击
“快速对话”或“资料对话”开始使用；也可以在两类对话的新建页面选择已有智能体。
模型凭据仍由服务端环境配置，不在智能体表单中填写。

后端入口仍为 app.main:app / 8000，前端默认端口仍为 5173；本日无需数据库升级。
新增前端不自动绑定或修改旧会话。
