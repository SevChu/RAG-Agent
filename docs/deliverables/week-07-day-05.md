## 配置解析开销

新增 `backend/scripts/measure_agent_runtime.py`。从 backend 运行：

```powershell
./.venv/Scripts/python.exe -m scripts.measure_agent_runtime --samples 100
```

脚本使用内存 SQLite，不读取 .env；每种情况预热 10 次后采样 100 次，每次新建 Session。
每个合成智能体仅有 r1；空间白名单分别为空或包含 100 个空间。SQL 计数有断言，
默认路径 0 次，绑定身份与版本 1 次，非空空间白名单再增加 1 次批量查询。

| 场景 | SQL / 次 | 2 个智能体 中位 / P95 ms | 1,000 个智能体 中位 / P95 ms |
|---|---:|---:|---:|
| 默认兼容解析 | 0 | 0.007 / 0.008 | 0.007 / 0.008 |
| 固定版本，空空间白名单 | 1 | 0.805 / 0.937 | 0.811 / 0.930 |
| 固定版本，100 个允许空间 | 2 | 1.615 / 1.737 | 1.617 / 1.820 |
| 创建前解析当前版本，100 个空间 | 2 | 1.895 / 2.188 | 1.844 / 2.049 |

计时包含配置查询、哈希/依赖验证和 Settings 副本构造，排除进程冷启动、Session 建立/关闭、
会话读写、检索、模型生成与网络延迟。这是本机合成微测量，不是磁盘数据库吞吐、完整请求
延迟或性能 SLA。没有据此新增缓存；每轮仍重新检查启停和服务端约束。

配置解析未创建模型网关、检索模型或评测器，网关包装委托既有实现。四供应商集成测试
确认一次快速回答没有配置引入的额外 HTTP 调用；总结/组卷的计划与修复调用保留原规则。
补充提示会增加输入长度，因此“无额外调用”不等于 Token 成本不变。
