## 本地启动

后端：

```powershell
cd D:\Agentic\backend
uv sync
uv run alembic upgrade head
uv run fastapi dev app/main.py --host 127.0.0.1 --port 8000
```

前端：

```powershell
cd D:\Agentic\frontend
npm.cmd install
npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

访问地址：

- 前端：`http://127.0.0.1:5173/`

## 建议演示流程

1. 打开课程空间并创建一门课程；
2. 再次创建同名课程，确认收到明确的名称冲突提示；
3. 进入课程并上传一份受支持的资料；
4. 再次上传内容相同的文件，确认按内容拒绝重复资料；
5. 查看文件名、类型、大小、状态和上传时间；
6. 勾选多份资料或使用全选，点击“批量删除”，确认弹窗显示准确数量；
7. 确认删除后，检查只有选中资料被删除；
8. 删除单份资料并确认二次确认弹窗；
9. 重新上传资料后删除课程，确认弹窗说明资料会被一并删除；
10. 查看快速对话、课程学习助手和设置入口；
11. 缩窄窗口，验证手机端侧边栏抽屉。
