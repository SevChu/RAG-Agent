## 验收范围

- 配置禁止未知字段/凭据字段、非法策略、错误范围、重复空间和重复评测引用。
- 配置哈希规范化，嵌套对象冻结；不匹配哈希拒绝读取/ORM 插入。
- migration 和 metadata 两种建库方式均执行数据库约束验证。
- revision 不可 UPDATE/DELETE，错配归属和半空绑定被拒绝；普通会话标题和删除仍可操作。
- 已有会话保持绑定 r1，追加 r2 不影响它；并发修改身份产生冲突。
- 使用旧版本合成数据库的 SQLite backup 副本升级；保留资料、两类会话、消息、引用与 Token。
- 回退保留旧内容及升级后新建会话/消息，但移除智能体配置和绑定；再次升级不伪造恢复。
- 正常资料空间级联删除在两次重建后仍有效，源测试数据库保持不变。
- 旧会话 API 回归；完整后端回归和静态检查通过。
- INSERT OR REPLACE 不能替换已有 revision 或会话，避免绕过 UPDATE/DELETE 触发器。
