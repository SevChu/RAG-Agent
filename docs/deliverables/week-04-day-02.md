## 人工验收步骤

### 1. 课程证据足够时不搜索

1. 进入“课程助手”，保持默认“课程资料 + 外部补充”；
2. 询问课程资料中有明确答案的简单问题，例如“什么是栈？”；
3. 预期回答只出现 `[课n]`，状态卡显示“课程证据已覆盖问题，未触发外部检索”；
4. 展开课程引用，确认文件、章节、位置与片段正确。

### 2. 明确要求外部补充时搜索

1. 提问“请联网查找官方资料，补充说明该知识点的当前版本变化”；
2. 预期状态卡显示外部检索完成以及合格/采用来源数；
3. 正文可以同时出现 `[课n]` 与 `[外n]`，两类编号各自从 1 开始；
4. 展开 `[外n]`，确认标题、发布方、URL、访问时间和证据摘要可核验。

### 3. 仅课程资料必须隔离 Web Search

1. 切换为“仅课程资料”；
2. 即使问题写明“请联网搜索最新资料”，也应只按课程资料回答或拒答；
3. 页面不应出现 `[外n]`，诊断信息显示“仅课程资料模式已关闭外部检索”。

### 4. 搜索失败后安全降级

可在本地 `.env` 临时设置 `EXTERNAL_SEARCH_TIMEOUT_SECONDS=0.001` 并重启后端，只用于制造
外部搜索超时；保留正常的 `LLM_REQUEST_TIMEOUT_SECONDS`。选择包含对应课程证据的问题，并
明确要求联网补充。

预期：页面显示黄色“已安全降级”，正文仍用 `[课n]` 回答课程已覆盖部分，外部失败原因可见，
回答不会因为 Web Search 失败而整体报错。验收后把超时恢复为原值（默认 60 秒）。

### 5. 来源差异展示

选择课程资料中的旧版本描述，再要求联网核验当前官方文档。如果两者确实不一致，预期正文
出现“资料差异”，并在同一部分并列引用至少一个 `[课n]` 与 `[外n]`；回答顶部显示“资料
存在差异”。自动化测试已覆盖模型声明冲突但未并列引用时必须拦截。

## 通过标准

- 普通课程问题不无条件联网；
- 需要外部资料时取得并展示真实 URL；
- `[课n]`、`[外n]` 清晰分离且不存在越界或模糊引用；
- `course_only` 不调用搜索网关；
- 搜索失败不拖垮已有课程答案；
- 真实冲突不被静默覆盖，而是并列说明。
