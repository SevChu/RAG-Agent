### 浏览器场景

1. 粘贴 test split 被拒绝，无法登记。
2. 数据创建、合法样本校验、登记、提交审核、批准。
3. 五步向导；非法 rank 拦截；提交已成功但响应被中断后保持输入和幂等键，重试返回同一任务；成功页面刷新可恢复。
4. 查看有效模拟产物、完整来源、无部署入口；桌面、390px 移动端、折叠侧栏检查。
5. 运行中断网提示、恢复轮询、取消到终态。
6. 测试服务器注入一次 Fake 失败，显式重试生成新任务并成功。
7. 数据审核撤销取消关联运行任务，展示 DATASET_REVOKED 对应原因。
8. 撤销版本不再出现在已审核版本选择器中。
9. 产物归档后默认列表隐藏，勾选归档后仍可追溯。
10. 产品版隐藏入口；直接 URL 不请求研究数据；三个管理 API 返回 403。
11. 实际 JSONL 文件上传、校验、登记、审核。
12. 从长名称智能体进入，自动选定版本；复核页面移动端与折叠侧栏可用，无横向溢出。
13. 无启用智能体的响应替身展示空状态及返回管理入口。

组件测试还覆盖切换任务后的迟到取消错误、离开产物页后的归档确认、重复点击、迟到异步响应、过期智能体版本阻止提交、离页停止轮询及产品直接路由。后端契约测试证明期望版本不符返回 409 且不创建任务；同键重放在智能体更新后仍返回原任务。

## 验证中处理的问题

Prettier 将内联多语句点击处理展开后触发 Vue 表达式解析失败，已改为独立函数并通过后续类型、构建和测试。下拉框显式增加无障碍标签；浏览器截图等待移动端/侧栏动画稳定，避免记录瞬态布局。

最终路由审查补充了取消操作的独立有效期票据，以及归档确认后的当前页面检查，避免旧操作污染新页面。新增两项组件回归；此后复跑全部 37 项前端测试、类型/Lint/构建，未重复浏览器主线。

首轮产品验证传入相对 basetemp，脚本切换目录后导致所有夹具创建失败，未执行业务测试；改用绝对临时目录重跑。测试脚本导入和格式问题已修正。CUA 及托管 Node 会话在此机器初始化失败，因此使用仓库已有 Playwright CLI 和 Chromium；未为此安装任何软件。
