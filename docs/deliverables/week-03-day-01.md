## 检索接口

```http
POST /api/courses/{course_id}/retrieval/search
Content-Type: application/json
```

最小请求：

```json
{
  "query": "栈和队列的主要区别是什么？",
  "top_k": 5
}
```

可选使用 `document_ids` 将检索限制在不超过 50 份已完成资料中。`top_k` 允许 1～20，
日 1 人工验收固定使用 5。

响应会返回：

- 排名、余弦相似度和完整 Chunk 文本；
- 原文件名、文件类型、章节路径；
- PDF 页码、PPTX 幻灯片号或文本行号；
- 本次纳入搜索的资料数、实际命中数、Embedding 设备和耗时；
- 明确的 `retrieval_mode=dense`，便于后续与重排、混合检索做对照。

开发服务启动后可在 `http://127.0.0.1:8000/docs` 直接调用，无需手写命令。

## 人工抽查不是“总共只看 5 条”

计划日 1 建议准备 **5 个代表性问题，每个问题检查 Top-5**。最多查看 25 条结果，但无需
逐字校对每个 Chunk，重点判断下列事项：

1. Top-5 中是否至少有一条能支持回答；
2. 第一条相关结果排在第几名；
3. 文件名、章节路径、页码/幻灯片号是否可追溯；
4. 是否混入其他课程或未完成资料；
5. Chunk 是否语义完整，是否出现明显跨章节拼接。

如果只是先确认接口能工作，可执行 5 个问题 × Top-3 的冒烟抽查；这不能替代正式的
Top-5 验收。
