日期：2026-09-10。用户确认 Day 4/5 简单测试验收无问题，后续可能继续测试与反馈，

## 使用与语义

管理卡片新增红色“删除”按钮。确认弹窗说明影响，可取消；删除成功后退出管理列表和
新会话选择。删除与停用分开：停用可重新启用，删除后不能通过编辑、复制、启用或恢复接口
重新使用。服务端保留身份、配置版本和历史绑定，旧会话可以查看，不能继续生成。

这是逻辑删除，不是彻底擦除数据；没有提供回收站或物理清理接口。原名称保留，现有唯一名称
约束仍生效，创建新智能体须使用不同名称。检查发生在新请求开始时，不强制取消已开始的生成。

## 实现

- AgentProfile 新增 nullable deleted_at；迁移 20260910_06 在 20260907_05 后仅增加一列。
- DELETE /api/agent-profiles/{id}?expected_row_version=N 返回 HTTP 200、data=null。
- 首次删除检查 row_version，同一事务记录删除时间、停用并递增版本；不新增 revision。
  版本过期返回 409，参数缺失/非法返回 422，身份不存在返回 404；重复删除幂等。
- 所有列表查询先过滤 deleted_at，再分页；详情/版本查询保留 deleted_at 供历史提示。
- 禁止对已删除身份编辑、复制、恢复及新建/继续会话；删除不依赖当前供应商或评测可用性。
- 前端删除确认带版本，冲突显示原因并刷新列表，不静默重试。删除分页最后一项后退回上一页。
- 两类对话共用删除状态提示，保留原绑定 revision，明确引导新建其他智能体会话。
