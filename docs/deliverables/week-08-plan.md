## 本周目标与范围

用户在科研模式中选择智能体、已审核的数据版本、训练目标及参数，创建可追踪、可取消、可重试的模拟训练任务，查看具有完整来源记录的模拟 Adapter。平台生命周期跑通后，为第九周真实 Trainer 接入提供接口。

本周不下载训练模型或数据集、不安装新训练依赖、不执行真实训练或官方 test、不把模拟结果用于回答，也不宣称模型质量提升。真实 Adapter 评测、晋级、运行绑定与回滚验证属于第九周；记忆、动态长上下文和国际化继续按后续路线推进。

## 跨周约束与环境安排

1. **训练模型与对话模型分开配置。** AgentProfile 的供应商/模型表示生成路由，不直接等于本地可训练模型。任务另存目标与 base model revision，首轮预留 Scorer/Reranker；按 2026-09-13 用户确认，第九周两项均为重点，生成大模型权重微调移出当前及后续已规划版本。
2. **任务固定来源。** 保存创建时的 AgentProfile revision/配置哈希、数据 revision/split 哈希、参数、seed、Trainer 版本和代码身份。后续配置修改不覆盖既有任务。
3. **旧配置保持兼容。** 不向历史 AgentProfile JSON 注入 Adapter 默认字段，不重算历史哈希，不改变旧会话绑定。任务关联智能体不等于部署产物。
4. **延续双版分离。** 本周训练入口和管理能力按科研功能实现；产品版保持资料、智能体和对话完整可用，无 Benchmark 或训练依赖前置要求。前端隐藏与后端能力检查一致，共用迁移链，不维护两套业务数据库。
5. **第八周采用原生 Windows。** Fake Trainer 使用现有环境，不需要 GPU。Day 1 只读记录 Python、现有依赖、内存/磁盘和 GPU 可见性。真实 Trainer 保持可替换接口，第九周选定模型后核验 Windows 或 WSL2/Linux 兼容性；本周不安装或切换环境。
6. **不把现有依赖当作训练就绪证明。** 当前 Torch/检索依赖不等于真实训练栈已合格。新增或升级 Transformers、PEFT、TRL、bitsandbytes 等先列明用途、版本、许可、体积和影响，再按路线单独处理；Fake Trainer 不导入训练栈组件。
7. **数据显式登记。** 不自动将资料空间、历史对话、Benchmark 或联网内容转成训练样本。开发验收使用合成数据及隔离数据库；真实数据必须明确提供并完成审核。

## Day 1：数据契约、TrainingDataset Registry 与迁移

### 实施内容

1. 编写微调平台设计决策，明确 Dataset/DatasetRevision、TrainingRun、TrainingEvent、ModelAdapter 的关系、不可变快照、审核语义、文件生命周期和科研边界。规划增量迁移，先实现数据登记所需结构。
2. 数据集使用稳定 ID 与不可变 revision，记录来源、许可/用途限制、PII 检查、审核意见、schema version、样本数、内容 SHA-256、split 哈希、去重方法及时间。修改内容或影响资格的元数据需新建 revision 并重新审核。
3. 最小导入范围为本地 UTF-8 JSONL 与 manifest；冻结 Scorer/Reranker 字段及标签范围，提供错误行报告。文件经受控入口复制到专用目录，限制大小/行数，拒绝路径穿越、链接越界和损坏文件，不接受任意服务端路径读取。
4. 审核状态采用 draft → pending_review → approved/rejected，并支持撤销资格；审核事件追加记录。许可不明、PII 待处理、空 split、格式错误或跨 split 重复的数据不得获准使用。基础扫描不能替代完整隐私审核，须保留审核说明。
5. 去重检查内容重复和来源分组，相同 source/group 不得跨 train/validation；近重复采用可复现规则或复核记录，不能只计算文件哈希就声称无污染。
6. 任务仅接受获准的 train/validation。test/Sealed Test 在训练选择器不可见，直接传 ID、混合 manifest 或别名也不能绕过。用合成 test fixture 验证边界，不打开现有封存测试集。
7. 提供列表、详情、revision、导入校验与审核 API；日志和列表默认仅返回汇总，不暴露样本正文或内部绝对路径。
8. 在隔离库验证从 `20260910_06` 升级、回退、再次升级和约束；保留原智能体、会话、消息、资料、Token 与保护触发器。正式库操作先准备备份和迁移演练证据。

### 验收与交付

- 合成合法数据可登记并审核；未知许可、PII 待处理、跨 split 重复、错误 schema 和篡改文件被拒绝。
- 已引用 revision 不可覆盖；撤销审核保留历史，并阻止新任务及未开始任务使用。
- 产品模式不能调用训练管理接口，普通智能体和历史对话不受影响。
- 交付设计决策、ORM/Schema/Repository/Service/API、迁移、定向测试和 `week-08-day-01.md`；记录环境清单及第九周待核验项。

## Day 2：任务状态机、Fake Trainer 与失败恢复

### 实施内容

1. 定义 Trainer 接口：配置校验、资源估算、运行、进度事件、取消及产物描述。实现确定性的 Fake Trainer，使用 seed 和测试专用故障注入复现成功、失败、慢执行、取消；不加载真实模型或访问外部服务。
2. 任务保存完整冻结配置，启动前重新检查文件哈希、审核资格、智能体状态与空间范围。权限收窄后不得借历史快照继续扩大数据访问。
3. 状态机采用 queued → running → succeeded/failed；queued → cancelled；running → cancelling → cancelled；意外终止记录 interrupted。非法迁移返回冲突，终态不能被迟到进度或完成回调覆盖。
4. 最小实现为本地单 worker、默认一次一个任务，原子领取与持久化所有权/心跳防止重复执行。状态、日志和进度持久化，不引入 Redis/Celery 或分布式调度。
5. 提供创建、列表、详情、分页日志、取消、重试 API。创建使用幂等键，同键异参返回冲突；重试创建新 run ID、记录 retry_of 并重新校验资格，保留原失败记录。
6. 日志记录事件序号、阶段、完成步数/总步数、时间和脱敏错误码，明确截断/保留规则。模拟进度/指标明确标识，不可展示为真实训练质量。
7. 取消请求幂等，排队任务直接取消，运行任务在检查点响应；覆盖取消与完成竞争。智能体停用/删除或数据审核撤销后，拒绝新任务、取消排队任务、触发运行任务取消并保留记录。
8. 重启识别失去 worker 的任务并标记 interrupted，不凭旧进度标记成功。页面刷新恢复观察；失败/中断通过显式重试新建任务，本周不实现真实 checkpoint 续训。
9. 估算展示输入、假设、可用资源和未知项；Fake 仅报告模拟任务资源。真实显存、耗时、成本缺少实测时显示“待评估”。

### 验收与交付

- 覆盖成功、排队取消、运行取消、失败、重启中断、重试、重复提交、并发领取及取消/完成竞争。
- 日志有序、进度不倒退、终态不被覆盖；记录 Fake 检查点间隔及实测取消响应。
- 测试阻断外部网络与真实模型加载；任务运行不改变普通问答路径。
- 交付 Trainer/Fake Trainer、执行器、管理 API、状态机测试和 `week-08-day-02.md`。

## Day 3：Adapter Registry、产物一致性与追踪

### 实施内容

1. Adapter 保存 run ID、智能体/revision、base model/revision、训练目标、数据 revision/split 哈希、参数、seed、代码/Trainer 版本、时间、产物 manifest/hash、评测状态和前驱关系。
2. Fake 只生成小型模拟 manifest，标记 `artifact_kind=simulated`、`deployable=false`、评测未执行。模拟指标与真实指标使用可区分字段；不生成权重，不伪装成可加载 Adapter。
3. 设计文件与数据库一致性流程：写临时产物、校验、原子移动、提交数据库引用；覆盖文件成功但数据库失败的恢复和孤儿产物核对。每个 run 最多一个 Adapter，重复回调不能重复登记。
4. 提供列表、详情、来源链、完整性状态和逻辑归档；已引用产物不硬删除，不清除任务和审核历史。产物缺失或哈希不符显示失效状态。
5. 校验训练目标、base model revision、数据 schema 与参数兼容性。LoRA/QLoRA 本周只用于契约和模拟流程，参数校验通过不等于真实硬件或训练栈支持。
6. 记录前驱/替代关系及未来回滚所需身份，本周不提供真实“启用到智能体”操作；后端拒绝模拟产物进入生成、检索或评分运行配置。
7. 预留真实产物和评测协议：第九周冻结 base 对照、validation 晋级、一次 test、指定 AgentProfile 新 revision 绑定及实际回滚验证；旧会话仍固定旧配置。

### 验收与交付

- 成功任务对应唯一模拟产物；失败/取消任务不登记成功 Adapter；篡改、缺失和重复事件正确处理。
- 创建任务后修改智能体或数据，不改变旧来源链；停用/删除后历史只读可查。
- 模拟产物无法部署，不改变现有模型路由或全局默认。
- 交付 Registry/API、一致性及边界测试、追踪契约和 `week-08-day-03.md`。

## Day 4：逐智能体五步微调界面

### 五步向导

| 步骤 | 用户操作 | 必须反馈的内容 |
|---|---|---|
| 1. 选择智能体 | 从智能体页进入或选择启用中的智能体 | 名称、固定 revision、允许数据范围；训练模型与对话模型分别配置 |
| 2. 选择数据 | 选择已审核版本及 train/validation | 数量、来源、许可、审核、去重摘要；test 不可选 |
| 3. 选择目标 | 选择 Scorer/Reranker 与模拟 base model | 当前为模拟运行；生成大模型训练不可提交 |
| 4. 配置参数 | LoRA/QLoRA、rank/alpha/dropout、学习率、batch、累积步数、epoch、seed、长度上限 | 前后端一致的范围/组合校验、参数说明及资源估算限制 |
| 5. 复核提交 | 核对版本、数据、目标、参数及预计步骤 | 按钮为“创建模拟训练任务”；防重复提交，进入任务详情 |

### 配套页面与交互

1. 数据登记、校验结果、审核意见、revision 和撤销审核页面，使完整流程无需手工 API。
2. 任务详情展示阶段、进度、日志、取消/重试、错误原因和来源快照；刷新与重进可恢复查看。
3. Adapter 列表/详情展示模拟标识、来源与完整性，不显示真实部署按钮。
4. 智能体停用、审核撤销、断网或版本冲突时保留表单并提示重新复核；过期异步响应不覆盖当前页面。
5. 复用现有 Vue、组件及请求方式，优先轮询并在离页时停止，不新增通信基础设施。
6. 检查桌面、折叠侧栏、移动端、长名称及错误状态；界面继续中文。产品版隐藏训练入口，直接 URL/API 访问也处理不可用状态。

### 验收与交付

- 浏览器完成登记/审核 → 五步提交 → 进度/刷新 → 成功产物；另完成取消、失败重试和审核撤销。
