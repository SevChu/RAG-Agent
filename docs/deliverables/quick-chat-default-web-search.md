# 独立会话默认联网验收说明

## 1. 交付目标

“快速对话 / 独立会话”不再固定禁用联网搜索。新会话的“自动联网”默认开启，服务端按当前消息
自动路由：信息型问题优先检索新资料，普通寒暄、纯创作/文本转换和明确要求不联网的消息直接交给
模型。该能力仍与课程资料隔离，不会读取课程知识库，也不会把独立会话写入课程对话。

## 2. 行为与边界

1. 前端每轮发送 `web_search=true`，用户可在快速对话工具栏关闭；后端请求字段默认值同样为
   `true`，旧客户端无需升级请求体即可获得联网能力。
2. 搜索成功后，合格结果作为不可信外部证据注入生成提示；回答使用 `[外n]` 标注，历史消息下方
   展示标题、发布者和可点击 URL。不存在的外部引用编号会被移除，但不会因此拦截整轮快速回答。
3. 指代型追问会把最近一条用户消息加入搜索查询，例如“它现在稳定了吗”能够携带上一轮主题；
   普通问题不额外调用查询改写模型。
4. 搜索超时、HTTP 503、无合格来源或服务端关闭搜索时，最终生成仍继续；历史状态明确记录失败原因
   和安全降级，不能把旧知识伪装成已联网核验的最新信息。
5. 搜索调用和最终生成调用均沿用现有分模型 Token 累计统计。

## 4. 人工验收

前后端启动方式不变：

```powershell
cd D:\Agentic\backend
.\.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8000
```

另开终端：

```powershell
cd D:\Agentic\frontend
npm run dev
```

打开 `http://127.0.0.1:5173/chat/new`，按顺序验收：

1. 确认工具栏“自动联网”默认开启，页面文案为“信息型问题自动联网”。
2. 提问“Python 当前稳定版本是什么，最近有哪些主要变化？”。预期正常回答，正文可见 `[外n]`，
   回答下方显示“已联网检索 … 个合格来源”和可点击来源卡片。
3. 接着问“它现在推荐用于生产环境吗？”。预期仍能围绕 Python 的上一轮主题搜索和回答，而不是把
   “它”当成未知对象；刷新页面后来源卡片和搜索状态仍存在。
4. 提问“你好”。预期直接回答，历史状态显示普通寒暄无需联网，不应等待一次无意义搜索。
5. 关闭“自动联网”，提问“今天 Python 官方有什么新消息？”。预期正常回答但状态显示本轮已关闭
   联网；重新创建独立会话时开关恢复默认开启。
6. 可选降级验收：临时停止可访问的外部搜索服务或使用会产生 503 的配置，再问一个最新信息问题。
   预期不出现整轮 HTTP 503 报错，回答提示最新信息可能不完整，历史状态显示已降级。
7. 回到课程学习助手，确认其课程范围、课程引用和混合搜索规则没有变化。
