# 第 5 周计划日 1 验收说明：通用智能体定位与界面语义迁移

## 当前交付状态

项目已经完成第一阶段产品迁移：用户界面由课程学习产品调整为通用智能体工作台，主概念统一为
Agentic、资料空间、空间资料和智能体对话。原有资料解析、检索、问答、总结、内容生成、联网
补充和会话恢复能力保持可用。

本日只迁移用户可见语义和产品设计，不修改 `Course`、`course_id`、`/courses`、数据库表、向量
payload 或既有生成协议。原第 5 周 100 条本地候选数据及评测代码继续保留，但不再是唯一
Benchmark，也没有运行真实模型评测。

## 完成内容

### 产品定位

- 品牌由 CourseMind 调整为 Agentic；
- “课程空间”调整为“资料空间”；
- “课程学习助手”调整为“智能体对话”；
- “课程资料、课程总结、课程问答”调整为空间资料、资料总结和资料问答；
- 组卷继续作为内容生成模板保留，不再定义整个平台用途。

### 界面迁移

- 侧边栏品牌、导航、历史分组、删除确认和空状态完成迁移；
- 资料空间列表、创建、删除、进入和资料管理文案完成迁移；
- 智能体对话的空间选择、来源范围、结果类型、诊断信息和输入提示完成迁移；
- 快速对话与设置页不再引用课程知识库；
- 兼容层继续使用旧 API 字段，避免破坏本地数据和会话恢复。

### 文档与后续模型

- README 调整为通用智能体定位；
- 第五周改为公开 Benchmark、经典检索基线和经典评分器基线；
- 新增 `ResourceSpace`、`AgentProfile`、`EvaluationSuite`、`FineTuneRun` 和
  `ModelAdapter` 目标模型；
