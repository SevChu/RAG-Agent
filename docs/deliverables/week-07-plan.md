## 本周目标与范围

支持多个智能体的独立配置、版本管理和使用。每个会话绑定创建时选定的 revision，后续修改
不覆盖旧会话配置。复用现有生成、检索和工具实现，避免为每个智能体复制代码。

本周不包含智能体自动协作、模型训练、Adapter 实现、长期记忆、动态长上下文或国际化。
AgentProfile 与研究评测 profile 分开管理；绑定评测配置不自动运行 Benchmark，也不获得生产
拦截权限。第六周 Day 2 维持 reject、Day 3 维持 deferred，NLI 继续仅作 offline/advisory。

## Day 1：数据结构、配置规则与迁移

1. 设计 AgentProfile 稳定身份、AgentProfileRevision 不可变快照与 Conversation 可空绑定。
2. 配置修改追加 revision；恢复旧配置也创建新 revision。停用保留历史，禁止新会话与继续生成，
   重新启用后恢复。旧会话保留兼容路径，不伪造历史配置。
3. 固定系统提示、供应商/模型、允许资料空间、Web Search 权限、上下文上限、在线检索策略和
   离线评测 profile 身份的配置契约。凭据只从运行环境解析，不进入配置快照。
4. 每个资料会话仍绑定一个允许的空间；快速对话继续不访问资料空间。
5. 编写 Alembic 增量迁移，在隔离数据库验证旧数据升级、回退、关联、约束及 ORM 一致性。
6. 明确回退丢失新增智能体配置和绑定；正式数据升级时保留备份，不通过删除数据库代替迁移。

验收：升级保留原资料、两类会话、消息、引用与 Token 记录；revision 不可覆盖；旧路径回归通过。

## Day 2：管理 API 与严格校验

用户于 2026-09-08 授权实施；基线包含已发布的 v1.2.2 界面补丁。

1. 新增 /api/agent-profiles 接口族：创建、列表、详情、复制、更新、停用/启用、版本列表/详情、
   从历史配置恢复。复制产生独立身份；历史保留，不提供破坏审计链的硬删除。
2. 校验供应商与模型对应、服务端白名单、空间存在性、工具允许列表、参数边界和检索数量关系。
3. 校验研究 profile 的版本、哈希、可用性和用途；不能将研究基线自动当成在线算法。
4. 配置优先级为服务端硬约束 → 会话 revision → 请求进一步收紧范围。绑定会话的冲突模型
   参数明确报错；旧兼容路径保留原模型选择行为。
5. 增加并发编辑保护，避免静默覆盖；同步 OpenAPI、API 文档与前端 DTO。

验收：管理操作通过接口测试，非法配置保存失败，复制独立，并发冲突明确，无凭据返回。

## Day 3：会话绑定与执行链路

2026-09-09 用户确认 Day 2 审批完成，并授权实施 Day 3。

1. 创建会话时固定 revision；后续不跟随最新版本，不允许原地切换智能体。
2. 统一解析运行配置，供问答、总结、组卷及适用的快速对话分支复用。
3. 接入模型路由（含计划/生成/修复调用）、系统提示、资料过滤、工具权限、上下文和检索参数。
4. 保留总结仅资料、快速对话无资料、引用校验、拒答、组卷校验和会话历史隔离。
5. 模型失效、空间删除、智能体停用等情况明确报错，不静默切换模型/空间/revision。
6. 消息诊断和 SSE 追加兼容字段，记录 revision、配置哈希和实际模型。配置绑定不冻结资料内容，
   也不保证外部生成模型回答逐字复现。

验收：A 绑定 r1 后创建 r2，A 仍使用 r1，B 使用 r2；越权和工具禁用不能绕过；同步与 SSE 一致。

## Day 4：前端管理与对话入口

2026-09-09 用户确认 Day 3 验收完成，并授权按计划实施 Day 4。

1. 列表显示名称、描述、模型、当前版本和启用状态，提供创建、复制、编辑、停用、开始对话入口。
2. 分组编辑提示、模型、空间、工具、上下文、检索和研究评测配置，并显示用途限制。
3. 版本列表显示变更说明和关键差异，支持从旧版本创建新版本；保存时说明只影响新会话。
4. 新建会话选择智能体和允许的空间；会话显示名称和绑定版本；切换智能体新建会话。
5. 完善空状态、模型未配置、表单校验、并发冲突和停用提示；验证桌面、折叠侧栏与移动端。

验收：界面完成创建 → 配置 → 对话 → 修改 → 新会话 → 对照旧版本 → 停用 → 查看历史。
