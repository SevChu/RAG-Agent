# Agentic 产品版

把自己的资料放在一起，围绕资料提问、整理重点，也可以创建适合不同用途的 AI 助手。
例如，为工作文档建一个资料空间，让助手帮你查找信息；为学习材料整理摘要或生成练习题。

你不需要准备评测集，也不需要了解 Benchmark，就能使用普通智能体的全部流程。
本页从第一次运行开始介绍；当前为 **v1.3.0 源码包**，需要先安装运行环境，不能双击直接使用。

## 你可以用它做什么

| 想做的事 | 从哪里开始 |
|---|---|
| 直接与 AI 聊一聊 | 打开“快速对话”，选择已配置的模型 |
| 根据自己的文件找答案 | 创建“资料空间”，上传文件，等处理完成后开始提问 |
| 整理资料重点 | 在资料对话中说明要总结的内容 |
| 根据材料出练习题 | 在资料对话中说明题型、数量和要求 |
| 给不同任务准备不同助手 | 在“智能体管理”中设置名称、回答要求、模型和可用资料 |
| 修改助手后查看以前的对话 | 旧对话保留原设置，新对话使用修改后的设置 |

答案质量取决于选用的模型和资料内容。重要结论请结合回答中的资料来源核对。

## 快速上手：先完成一次对话

第一次使用可以先只配置一个模型，启动后打开“快速对话”。这一流程不需要上传文件，
也不需要准备读取资料所用的本地模型。之后再按下一节启用自己的资料即可。

### 1. 准备运行环境

请先安装 Python 3.11 或更高版本、uv，以及 Node.js 24.12 或更高的兼容版本。
uv 用来安装后端所需组件，Node.js 用来运行网页界面。下面的命令适用于 Windows PowerShell。

将产品版 ZIP 解压到一个新文件夹，并在该文件夹打开终端。文件夹内应能看到 `backend`、
`frontend`、`scripts` 和 `.env.example`。升级已有项目时先备份，避免直接覆盖正在使用的目录。

### 2. 填写模型连接信息

首次运行时，复制一份设置文件并打开：

```powershell
Copy-Item .env.example .env
notepad .env
```

已有 `.env` 时直接编辑，保留原设置。找到 `AGENTIC_EDITION`，让它保持 `product`。
接着填写一个你有权使用的模型服务。下面以 DeepSeek 为例：

```dotenv
AGENTIC_EDITION=product
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=填写你的APIKey
LLM_MODEL=填写你可用的模型ID
LLM_AVAILABLE_MODELS=填写你可用的模型ID
```

API Key 是连接模型服务的凭据；模型 ID 请使用服务商提供的实际名称。若只用一个模型，
最后两行填写相同的 ID 即可。使用 Qwen、Kimi 或 GLM 时，填写示例文件中对应的地址、Key
和模型列表。保存文件，API Key 留在自己电脑上，不要分享。

### 3. 安装组件并启动

在解压后的主文件夹运行：

```powershell
powershell -File scripts/install.ps1 -Edition product
```

首次安装需要下载运行组件，可能耗时较长。脚本不会下载评测集或本地模型。
安装成功后，在同一窗口启动后台服务：

```powershell
cd backend
uv run --no-sync alembic upgrade head
uv run --no-sync python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

其中 `alembic upgrade head` 用来准备或升级保存资料和对话的数据库；升级已有数据前先完成备份。
保留这个窗口，再从主文件夹打开第二个终端，启动网页界面：

```powershell
cd frontend
npm run dev
```

### 4. 打开页面，发送第一条消息

浏览器打开 [Agentic](http://127.0.0.1:5173)，进入“快速对话”，选择模型后发送一条消息。
如果模型不可选，请检查 Key 和模型列表是否填写完整；修改 `.env` 后需要重新启动后台服务。

使用期间保留两个终端窗口；结束使用时可分别按 `Ctrl+C` 停止服务。

## 再使用自己的资料

围绕文件提问需要本地的“资料查找”模型。它们负责找出相关段落并排序，和前面负责回答的
在线模型分工不同，也不是评测数据。请准备好模型文件，并在 `.env` 填入实际所在路径：

| 用途 | 需要的模型 | 设置项 |
|---|---|---|
| 找出相关资料段落 | BGE-M3 | `EMBEDDING_MODEL_PATH` |
| 把更相关的段落排在前面 | BGE Reranker v2 M3 | `RERANKER_MODEL_PATH` |
| 识别扫描 PDF 中的文字 | PaddleOCR 模型，仅扫描文件需要 | `PADDLE_OCR_BASE_DIR` |

模型文件不在源码包中，软件不会自动下载；可请负责部署的人按项目配置准备。
完成路径设置并重启后台后：

1. 创建一个资料空间，上传与本次任务有关的文件。
2. 等待资料处理完成，再在该空间开始对话。
3. 说明你要查找、总结或出题的内容，并查看回答给出的资料来源。

## 创建和维护自己的智能体

进入“智能体管理”，给助手起名，选择模型，写下回答要求，再选择允许使用的资料和工具。
保存后即可开始对话。之后修改设置只影响新对话，已有对话继续使用创建时的版本。

复制会得到一个独立助手；恢复旧设置会生成一个新版本。停用可以暂时阻止使用；删除会将其
从列表移除并阻止继续生成，但保留以前的对话和配置记录。

从科研模式带来的旧研究关联会保留为历史记录，不影响这里的日常使用。产品版不展示研究
设置，也不要求你补齐研究文件。

## 常见情况

| 情况 | 可以先检查什么 |
|---|---|
| 页面打不开 | 两个终端是否仍在运行，地址是否为 `http://127.0.0.1:5173` |
| 能打开页面，但模型不可选 | 对应服务商的 Key 和模型列表是否完整；修改后是否重启后台 |
| 快速对话可用，但资料处理失败 | 本地模型路径是否正确，资料处理状态是否显示具体错误 |
| 回答提示资料不足 | 文件是否处理完成，当前智能体是否允许使用该空间，资料是否包含答案 |
| 想升级已有安装 | 先备份数据库、上传文件和向量索引，再按新版本说明升级；不要删库重装 |

## 版本与文件说明

产品版保留日常智能体、资料和生成能力，不附带研究脚本、评测模块或 Benchmark 结果。
若需要开展算法实验，请使用研发/科研版；单改产品包的设置无法补上缺失的科研文件。

当前适合本地单用户使用。资料、索引、对话和设置由本机保存；使用在线模型回答时，会将本轮
需要的请求内容发往配置的服务商。源码包不包含你的 Key、资料、数据库、模型或备份。
