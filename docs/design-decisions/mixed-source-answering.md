## 产品决策

最终问答界面只提供两个回答范围：

1. `课程资料 + 外部补充`：最终产品默认值；
2. `仅课程资料`：完全关闭 Web Search，只允许已完成入库的课程资料支撑回答。

“允许外部补充”不等于每次提问都必须联网。混合模式应先检索课程资料，在课程证据不足、
问题包含未覆盖的子要求、用户明确要求外部信息或问题具有明显时效性时调用 Web Search。
这样保留课程材料的主导地位，同时控制延迟和搜索成本。

计划日 1 已展示回答范围选择器，并明确标注当前回答链路仍按课程资料运行；真实外部搜索
适配器可由独立验收脚本验证。计划日 2 完成条件路由、混合生成与降级后，才把混合选项视为
完整可用能力，不能仅凭选择器声称已经联网作答。

## 来源与引用分类

| 类型 | 正文标记 | 可作为事实依据 | 必须展示的信息 |
|---|---|---|---|
| 课程资料 | `[课1]`、`[课2]` | 是 | 文件名、章节、页码/幻灯片号/行号、原文片段 |
| 外部资料 | `[外1]`、`[外2]` | 是，通过质量与相关性检查后 | 标题、发布机构或网站、URL、访问时间、可核验片段 |
| 基于证据的推导 | `**综合推导：**` | 是，但前提必须有课程或外部引用 | 推导正文及其前提引用 |
| 模型已有知识 | `模型补充知识（未核验）` | 默认否 | 明确的未核验提示，不生成伪造引用 |

模型训练记忆没有稳定的原始出处，不能被包装成“外部资料”。最终实现应优先把课程外事实
转化为带真实 URL 的 Web Search 证据；无法取得可核验来源时，不得用模型记忆静默补齐。

## 外部来源优先级

外部搜索和排序按以下优先级处理：

1. 同行评议论文、论文数据库、学术期刊和学术出版社；
2. 大学、科研机构、标准组织和政府科研网站；
3. 官方技术文档、规范和项目原始文档；
4. 其他具有明确作者、发布日期和参考来源的专业技术网站。

聚合搬运站、无作者 SEO 页面、论坛帖子、自媒体和无法确认出处的内容不得作为首选事实
证据。搜索结果质量不足时，应保留课程回答并说明没有取得合格的外部补充，而不是降低来源
标准。

## 回答与降级规则

### 课程资料 + 外部补充

1. 先运行课程范围 Dense → Reranker → 证据门；
2. 判断课程证据是否覆盖问题及各个子要求；
3. 必要时调用 Web Search，并对来源质量、相关性和重复项进行处理；
4. 分别编号课程证据和外部证据，再交给 LLM 组织回答；
5. 服务端校验正文中两类编号都对应真实来源；
6. Web Search 超时、限流或无合格结果时，退回课程资料回答，并展示外部检索失败或无合格
   来源的状态；不得因此让整个课程问答失败。

### 仅课程资料

- 不发起任何 Web Search 请求；
- 沿用第 3 周已经验收的检索、重排、证据门、引用校验和资料不足拒答；
- 课程外问题继续拒答，用于课程复习和封闭知识库评测。

## 技术落点

现有生成客户端调用 DeepSeek OpenAI-compatible Chat Completions。混合功能实施时增加独立的
Web Search 适配器，并复用同一个 `LLM_API_KEY`。用户已确认该 Key 具有 Web Search 权限。
不得把 Key 返回前端、写入日志、测试夹具或 Git。

DeepSeek V4 支持工具调用；其 Anthropic-compatible API 文档列出了服务端
`web_search_tool_result` 支持。实施时必须用最小真实请求验证当前账号、模型和接口的实际
返回结构，再固定解析契约，不能只根据模型名称推断搜索已经发生。

参考：

- [DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/)
- [DeepSeek Anthropic API compatibility](https://api-docs.deepseek.com/guides/anthropic_api/)

建议扩展的数据契约：

- 请求增加 `answer_scope = course_and_external | course_only`；
- 默认值为 `course_and_external`；
- 引用增加 `source_type = course | external`；
- 外部引用增加 `title`、`publisher`、`url`、`accessed_at` 和证据片段；
- 返回外部搜索是否触发、搜索状态、使用结果数和降级原因；
- 课程资料和外部资料使用独立编号空间，避免 `[1]` 的来源类型含糊。

## 用户验收重点

1. 默认选项是否为“课程资料 + 外部补充”，并能切换到“仅课程资料”；
2. `[课n]` 与 `[外n]` 是否一眼可区分且都能展开核验；
3. 课程资料足够时是否保持课程材料为主要依据；
4. 外部来源是否优先来自论文、大学、研究机构、标准组织或官方文档；
5. “仅课程资料”是否保持原有边界，课程外问题不使用 Web Search 或模型常识回答；
6. 外部搜索失败时是否仍能返回课程范围内的答案并明确降级状态；
7. 课程资料与外部来源冲突时是否并列说明，而不是静默覆盖课程结论。
