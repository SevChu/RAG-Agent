- 数据下载：未批准，禁止下载

## 背景与结论

项目现有的资料解析、检索、引用问答、联网补充、总结、内容生成、多轮会话和 token 统计并不只
适用于课程学习。产品定位调整为：Agentic 是一个本地优先、资料可追溯、支持评测与后续微调
的通用智能体实验平台。原有学习能力作为智能体能力模板继续存在。

## 产品概念

| 旧概念 | 新概念 | 第一阶段内部实现 |
|---|---|---|
| CourseMind | Agentic | 修改用户可见品牌，包名暂不变 |
| 课程空间 | 资料空间 | 继续复用 `Course` 数据模型 |
| 课程资料 | 空间资料 | 继续复用 `Document.course_id` |
| 课程学习助手 | 智能体对话 | 继续复用 `/assistant` 路由 |
| 课程对话 | 空间对话 | 继续复用 Conversation 表 |
| 课程总结 | 资料总结 | 继续复用 summary task |
| 智能出题 | 内容生成模板 | 继续复用 exam task，后续模板化 |
| 课程记忆 | 空间记忆 | 后续独立里程碑实施 |

## 第一阶段兼容策略

本阶段只修改用户可见界面、产品说明和文档，不立即重命名 `Course` 类型、`course_id` 字段、
`/api/courses` 路径、现有数据库表、向量 payload 和组件文件名。这样可以避免为纯命名变化承担
数据库重建、双写、旧会话恢复和向量全量迁移风险。

## 目标领域模型

### ResourceSpace

资料空间负责知识与数据隔离，可以承载技术文档、论文、制度、项目文件、个人笔记或公开
Benchmark 语料，不再假定内容一定是课程。

### AgentProfile

每个智能体至少包含名称、版本、系统提示词、默认模型、可访问资料空间、工具与联网策略、上下文
与记忆策略、默认评测套件，以及当前启用的基础模型或 Adapter。智能体与资料空间最终为多对多关系。

### EvaluationSuite

评测套件关联数据集版本、任务类型、评分器版本、阈值和报告协议。被测系统结果与评分器输出必须
独立保存，不能覆盖人工或公开金标。

### FineTuneRun 与 ModelAdapter

微调任务记录基础模型、数据版本、LoRA/QLoRA 参数、随机种子、硬件、日志、checkpoint 和评测
结果。Adapter 必须经过固定验证、独立测试和用户批准后才能绑定智能体。

## 公开数据与自有数据

公开 Benchmark 用于建立可比较的经典基线，自有人工金标用于验证真实产品任务。数据状态固定为：

```text
candidate → approved → downloaded → verified → frozen
```

未经用户逐项审批不得下载。公开 test split 不参与提示、权重、阈值或规则开发。

## 评分算法研究协议

先冻结经典检索指标、Exact Match、Token F1、ROUGE-L、BERTScore、RAGAS 与 RAG Triad，再研究
融合、校准和小模型评分器。任何自研方案都必须使用相同数据、split 和报告协议与经典基线比较。

## 第一阶段非目标

- 不下载候选公开数据集；
- 不修改数据库字段和向量 payload；
- 不实现多用户权限；
- 不启动模型训练或实现完整微调界面；
- 不删除已有总结、组卷、长上下文或空间记忆设计资产。
