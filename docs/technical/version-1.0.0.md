# Agentic 1.0.0 基线说明

## 1. 版本定义

1.0.0 是项目第一个“核心功能闭环完整”的本地基线：用户可以创建资料空间、上传并索引五类资料、进行可追溯问答、生成总结和试卷、使用快速对话和条件联网、切换已配置模型，并恢复会话与查看 Token。

这里的 1.0.0 表示**本地功能与文档基线**，不表示已经完成 GitHub 发布、生产部署或研究路线的全部功能。

## 3. 冻结的兼容契约

1.0.0 保留下列历史内部名：

- SQLite：`courses`、`course_id`；
- API：`/api/courses/...`；
- Python：`Course`、`CourseService` 等；
- 前端：`CourseSpaceView`、`StudyAssistantView` 等组件文件名；
- 评测任务：`exam` 仍承载组卷/题目内容生成。

用户可见语义已经迁移为资料空间和智能体。后续重命名内部契约属于潜在破坏性变化，必须有数据库迁移、API 兼容策略和完整回归。

## 4. 数据与版本兼容

### SQLite

1.0.0 数据库必须升级到 Alembic `20260810_04` 或更新 head。发布不能通过删除数据库来解决迁移问题。

### Qdrant

默认 Collection `knowledge_chunks_v1` 使用 1024 维 Cosine。改变 Embedding 维度、Payload 必填字段或分块逻辑时，必须评估新 Collection 和全量重索引。

### 本地模型

OCR、Embedding 和 Reranker 不包含在 Git 仓库中。发布说明应记录模型名称、来源、许可、期望目录和可选哈希，但不应直接重新分发模型权重，除非许可证明确允许。

### API

当前 API 没有 `/v1` 前缀。1.0.x 应只进行兼容增加和修复；破坏字段、路径或语义时应引入明确版本策略。

## 5. 已知限制

### 产品与安全

- 单用户，无登录、权限、租户和共享。
- API 无认证，不能直接公网暴露。
- 没有敏感信息检测、资料脱敏或恶意软件扫描。
- 资料证据会发送给外部模型 API。

### 资料与检索

- 复杂公式、图示、SmartArt 和复杂表格语义有限。
- 当前主检索是 Dense + Reranker，没有已冻结 BM25/融合基线。
- Qdrant Local 适合单进程，不适合多 worker。
- 内容角色和概念门控是规则/模型组合，仍需要公开数据验证。

### 对话与生成

- 只有有限上下文，没有长期记忆和 100k 动态上下文。
- SSE 是完整回答的后端分段，不是上游原生 token streaming。
- 停止 SSE 不保证取消已经完成的上游调用费用。
- 生成代码不执行，也没有自动判题。
- 不同供应商对 JSON 模式的兼容性需要逐模型验收。
- Web Search 只通过 DeepSeek 适配器提供。

### 研究平台

- 没有 AgentProfile CRUD、版本化或权限。
- 没有微调数据治理、训练调度、GPU 队列、Adapter 注册和界面。
- 没有已获批公开数据、经典 Benchmark 结果和评分器校准报告。
- 本地 100 条候选数据不是最终自有标准测试集。

## 9. 后续研究路线

推荐顺序：

1. 用户逐项审批公开数据。
2. 建立统一 Dataset Registry 与 Adapter。
3. 冻结 BM25、Dense、融合和 Reranker 检索基线。
4. 冻结 EM/F1/ROUGE-L/BERTScore 与 RAG 评分器基线。
5. 分析评分器相对公开标注和人工审核的误差。
6. 提出融合、校准或微调后的评分算法。
7. 建立 AgentProfile，再设计逐智能体微调界面。
8. 最终构建自有人工金标集，并与公开 Benchmark 联合报告。

任何改进都应固定数据哈希、split、代码提交、配置、模型版本、随机种子、硬件、延迟、Token 和资源使用，且不使用 test split 调参。
