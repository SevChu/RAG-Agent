## 计划日 1：课程范围 Dense 检索

实际实施日期：2026-08-03。

### 目标与边界

建立后续 RAG 的可复现基础检索基线：使用现有 BGE-M3 Dense Vector，在单门课程及可选
资料范围内返回 Top-K Chunk 和完整来源元数据。今天不实现重排、生成、引用编号、改写、
拒答与流式响应。

### 已完成

- 新增独立 `DenseRetriever`，负责查询标准化、查询向量化和课程范围 Qdrant 搜索；
- 新增 `POST /api/courses/{course_id}/retrieval/search`；
- 默认 Top-5，支持 1～20 和最多 50 个资料过滤；
- 只把数据库状态为 `completed` 的资料 ID 传给向量库，避免旧向量或处理中资料进入结果；
- 返回相似度、Chunk、文件、章节、页码、幻灯片号、行号、设备与耗时；
- 检索和索引复用同一模型与 Qdrant Client，并使用既有运行时锁串行化本地存储操作；
- 无可检索资料时直接返回空结果，不加载 BGE-M3；
- 新增检索服务与 API 自动化测试；
- 创建本地资料整理目录 `data/source-materials/数据结构/`；
- 建立 5 问 × Top-5 人工抽查规则，目标初始 `Hit@5 >= 80%`。

### 关键决策

1. 日 1 固定 Dense 基线，便于后续把重排与混合检索的收益单独量化；
2. 人工验收单位是“5 个问题”，不是总共 5 条命中；
3. 来源元数据从检索接口原样提供，但引用编号与答案内引用留到后续生成链路；
4. 正式库原有课程是“计算机组成原理”，不会被覆盖；数据结构作为新增主测试课程；
5. 重排模型目录虽已获准，但实际下载仍然没有获得批准。

### 验收结论

用户于 2026-08-03 确认五问 Top-5 的相关性与来源判断，计划日 1 通过验收。

### 五问真实抽查

- 数据结构课程 3/3 份资料状态为 `completed`；
- 运行设备 CUDA，首次查询 542.39 ms，预热后平均 98.11 ms；
- 主题相关 `Hit@5=5/5`，25 条结果均未跨课程；
- 严格区分主题相关与事实可用性：栈/队列题只命中未标明正误的练习题题干，因此安全支持
  计为 4/5；
- 二分/折半查找样本的首条直接相关结果为 Rank 4，保留为重排基准；
- 详细证据记录于 `docs/deliverables/week-03-day-01-retrieval-review.md`。

### 后续证据安全决策

- 不能只依赖 Reranker，因为未作答练习题同样与问题高度相关；
- 后续增加正文、例题、题干、答案、代码等 `content_role`；
- 将“语义相关性”与“是否有资格作为事实证据”分开判定；
- 对复合问题执行子问题证据覆盖检查，证据缺失时部分回答或拒答；
- 引用只能绑定合格证据，孤立题干不能支撑事实结论；
- 将栈/队列陷阱样本纳入固定回归集，并跟踪 `evidence_hit@5` 与
  `unsafe_evidence_rate`。

### 验收后新增体验改进：索引处理进度

用户于 2026-08-03 提出：上传结束后，文件长时间显示“处理中”但无法判断还需等待多久。
该项作为计划日 1 的验收后改进记录，当前尚未实现，不影响已经通过的 Dense 检索基线。

- 前端现有百分比只表示文件上传，不能复用为后台索引进度；
- 后端将持久化 `progress_percent`、`processing_stage` 和可选阶段明细；
- 解析/OCR、分块、Embedding、Qdrant 写入分别按真实页数或批次数推进；
- 资料列表在“处理中”状态下显示进度条、百分比和当前阶段，并继续沿用 2 秒轮询；
- 百分比保持单调，`completed=100%`，失败保留最后阶段和失败原因；
- 进度用于解释任务推进，不承诺精确 ETA；详细设计与验收标准见计划日 1 验收说明。
