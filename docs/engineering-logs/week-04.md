## 已确认约束

- 问答默认范围为“课程资料 + 外部补充”，同时保留“仅课程资料”；
- 混合模式先检索课程资料，只在覆盖不足、明确要求外部内容或问题具有时效性时搜索；
- 课程与外部来源分别使用 `[课n]`、`[外n]`，不共享编号空间；
- 外部来源优先论文、大学、科研机构、标准组织和官方文档；
- 模型记忆不能伪装成外部来源，外部事实必须对应真实搜索结果 URL；
- Web Search 失败时不能拖垮课程回答，具体降级编排在计划日 2 实施；
- 总结默认仅课程资料并包含考试重点；出题默认 20 题、默认偏向 C++，课程改编题不超过
  30%，外部补充题不超过 20%。

## 计划日 2：LangGraph 条件搜索与混合回答

### 完成内容

- 新增 LangGraph 依赖和 `ConditionalAnswerGraph`，状态图包含课程覆盖判断、条件搜索与答案
  生成节点；
- `course_only` 在覆盖判断节点直接进入课程生成，搜索网关调用次数保持为零；
- 混合模式在无合格课程证据、最高相关度低于阈值、多个子要求未覆盖、用户明确要求外部资料
  或问题具有时效性时触发 Web Search；
- 课程证据充分且问题没有外部/时效需求时不搜索，保留课程材料主导地位；
- 搜索成功后把课程证据与外部证据分别编号，混合生成器只接受 `[课n]`、`[外n]`，拒绝
  模糊 `[n]`、越界编号和无引用回答；
- 模型声明或正文出现来源冲突时，必须生成“资料差异”部分，并同时引用课程与外部证据；
- 搜索超时、HTTP 错误、无合格来源或适配器异常时不终止问答：存在课程证据则自动回到
  课程生成并记录 `fallback_applied=true`，否则保持证据不足拒答；
- 前端展示条件搜索原因、合格/采用来源数、安全降级提示、来源差异状态和外部引用链接；
- 搜索判断、失败原因、采用数量和冲突标志随回答写入会话快照，无数据库迁移。
